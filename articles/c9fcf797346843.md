[herdr](https://herdr.dev)は、コーディングエージェント向けのターミナルマルチプレクサです。サイドバーには動作中のエージェント名を表示するagentパネルがありますが、この名前のラベルが薄すぎて私の環境ではほとんど読めませんでした。

![サイドバーのagentパネル、設定前。herdr / agent-panel-dim-fixの行が薄く沈んで見える](/images/c9fcf797346843/01.webp)

これは、`config.toml`に設定を足せば、次のように比較的はっきり読めるようになります。

![サイドバーのagentパネル、設定後。herdr / agent-panel-dim-fixの行がはっきり読める](/images/c9fcf797346843/02.webp)

## configで直す

```toml
[ui.sidebar.agents]
rows = [
  ["state_icon", "workspace", "tab"],
  [{ token = "agent", dim = false }],
]
```

herdrのソース(`src/ui/sidebar.rs`)では、agentパネルの名前ラベルに`fg(overlay0).add_modifier(Modifier::DIM)`が使われています。`dim = false`はこの`Modifier::DIM`を上書きで取り除く指定です。

## IssueやPRもあるが設定で回避するのがよさそう

そもそもデフォルトの見た目は薄すぎますが、[Issue #1783](https://github.com/herdrdev/herdr/issues/1783)ではカスタマイズできるようにしているからとIssueはcloseされていました。また[PR #1727](https://github.com/herdrdev/herdr/pull/1727)では、別の箇所ですが同じ`fg(overlay0)`+`Modifier::DIM`の組み合わせが、特定のテーマでアクセシビリティの基準を満たしていないという指摘もありました。(PRはContribution Guidelineに沿っていないのでと自動closeされています。)

というわけで、デフォルトが変わる可能性は低そうなので、設定で回避することが現状ベストな方法です。
